# VeriDesk — grounded RAG support assistant

Built for **The Engineer's Code 2026 — RAG Chatbot Builder** (SENTEC, NED UET).
Upload a product manual (PDF). VeriDesk answers customer questions **only from that document**, cites the page for
every claim, says so when the manual doesn't cover something, and stays composed under adversarial users.

## Quick start
```bash
pip install -r requirements.txt
copy .env.example .env          # then add an LLM key (see below)
python scripts/ingest.py "UGProspectus2025.pdf"   # index the competition PDF (scanned → OCR, cached)
python run.py                   # http://127.0.0.1:8000
```

### LLM configuration used in the competition
The competition PDF (NED UG Prospectus 2025) is a **scanned, image-only PDF**. Text was transcribed page by page with
Gemini vision OCR during ingestion (cached in `data/pages/`). Answers are generated by **Groq** through its
OpenAI-compatible API, rotating across models on rate limits:
```
LLM_PROVIDER=openai
OPENAI_API_KEY=<groq key>
OPENAI_BASE_URL=https://api.groq.com/openai/v1
OPENAI_MODEL=qwen/qwen3.8-27b
OPENAI_FALLBACK_MODELS=openai/gpt-oss-120b,openai/gpt-oss-20b
LLM_FALLBACKS=gemini,extractive          # backup: Gemini flash-lite, then cited quotes
GEMINI_API_KEY=<gemini key>
GEMINI_MODEL=gemini-flash-lite-latest
OCR_ENABLED=0                            # OCR already done and cached; never re-run paid OCR by accident
```
**OCR cache included:** `data/pages/0b3c2a3207758ba9/` holds the verbatim OCR transcription of the prospectus
(121 of 122 pages, one JSON file per page). With it, indexing the prospectus needs **no OCR and no paid API**:
put `UGProspectus2025.pdf` in the project folder, set `OCR_ENABLED=0`, and run
`python scripts/ingest.py UGProspectus2025.pdf` (the cache is matched by the PDF's SHA-256 hash).

Answer chain: **Groq → Gemini (backup) → extractive quotes**. If every model fails, the bot still answers with
verbatim, cited passages and never invents content.
Without any key the app still works in **extractive mode** (cited verbatim quotes, no generation).

### Measured results
* Prospectus test set (34 questions, `eval/dataset_prospectus.json`): **34/34**, Recall@6 26/26, MRR 0.878,
  0 invalid citations, 0 unverified numbers (Groq qwen3.8-27b).
* Known gap: PDF page 81 (printed 74), a rotated seat-allocation table, could not be OCR'd and is not indexed.

## Pipeline
PDF → PyMuPDF extraction (pages, headings from font sizes, tables as markdown; pdfplumber/pypdf fallbacks) →
heading-aware chunks (~1000 chars, 150 overlap, tables atomic, section path on every chunk) →
`BAAI/bge-small-en-v1.5` embeddings (local CPU) in **FAISS** + **BM25** → Reciprocal Rank Fusion top-6 →
evidence gate → **Gemini** (Claude/OpenAI/Ollama switchable) with numbered evidence and mandatory `[n]` citations →
validation (invalid citations removed, unverified numbers flagged, prompt-leak canary) → streamed UI with page
citations and an evidence inspector. Details: [docs/TECHNICAL_NOTES.md](docs/TECHNICAL_NOTES.md).

## Repository map
| Path | What |
|---|---|
| `app/ingest.py` | PDF extraction + quality checks |
| `app/chunking.py` | structure-aware chunking |
| `app/embeddings.py`, `app/store.py` | embeddings, FAISS + BM25 index, hybrid search, persistence |
| `app/guard.py` | injection / hostility / extraction detection, document-injection flags, canary |
| `app/prompts.py` | system prompt and evidence formatting |
| `app/rag.py` | orchestration, evidence gate, validation, extractive fallback |
| `app/llm.py` | Gemini / Claude / OpenAI / Ollama streaming |
| `app/server.py`, `static/index.html` | FastAPI API + single-page UI |
| `scripts/eval.py` | evaluation suite (Recall@k, MRR, behaviour, citation validity, latency) |
| `scripts/make_test_pdfs.py` | **synthetic** rehearsal PDFs (not the competition document) |
| `eval/dataset_synthetic.json` | 53 labelled test questions for the synthetic manual |
